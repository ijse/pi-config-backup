# Pi 半自动模型路由方案

日期：2026-09-14。状态：待用户审阅；仅写方案，尚未修改生效配置。

## 目标与范围

用户选择“半自动升级”：日常默认使用相对经济的 Copilot 模型，明确简单任务可降级；更昂贵模型必须确认。用本地确定性规则判断，不增加分类模型请求，不承诺准确识别所有任务或固定节省比例。

只新增用户级本地扩展并更新模型相关配置；不改 Pi 核心、OAuth 凭据、Copilot 端点、Subagent 插件、现有 loadout、压缩策略或其他工具。

## 模型配置

- `github-copilot/gpt-5.6-terra`：新会话默认，medium。
- `github-copilot/gpt-5.6-luna`：明确简单任务，low。
- `github-copilot/gpt-5.6-sol`：复杂任务候选，medium，需确认。
- `github-copilot/gpt-6-astra`：高风险深度任务候选，medium，需确认。
- 四个模型 ID 已在本地 `models-store.json` 中查到；是否有实际调用权限尚未实测。
- `settings.json` 中替换 `enabledModels`，依次为以下 ID（全部加 `github-copilot/` 前缀）：`gpt-5.6-terra`、`gpt-5.6-luna`、`gpt-5.6-sol`、`gpt-6-astra`、`gpt-5.3-codex`、`gpt-5.4-mini`、`gemini-3.8-flash`、`gpt-5.5`、`grok-4.6`、`gpt-5-mini`、`gpt-5.4`、`mai-code-1.1-flash`、`gemini-3.7-flash`、`gemini-3.6-flash`、`grok-4.5`。
- 只允许修改 `defaultProvider`、`defaultModel`、`defaultThinkingLevel`、`enabledModels` 及 `modelThinkingLevels` 中上述四档键；其他设置及已有每模型键保留。
- 用 `modelThinkingLevels` 设置上述四个模型的默认思考强度，`defaultThinkingLevel` 保持 medium。用户仍可手动调整。

## 运行策略

### 任务边界与稳定性

- “路由任务”是一个会话中新的一段工作，由新会话或用户 `/route reset` 明确开始，不假装自动理解语义任务边界。
- 仅在 TUI 中、agent 空闲、来源为 interactive 的普通用户输入上处理。带 streamingBehavior 的排队/steering 输入、扩展注入输入、斜杠命令、RPC/print/JSON 均不自动路由或弹窗，原文原样继续。
- 无路由记录的已有会话采用保守手动锁定模式，不擅自覆盖恢复的模型；用户 `/route auto` 才授权接管。空白新会话且当前为默认 Terra 时自动启用；显式以其他模型启动时锁定。
- 一个任务只允许首次独立请求从 Terra 自动降到 Luna；后续保持模型，不因“继续”“好的”等短消息降级。
- Luna 遇到非明确简单的实质请求时，自动恢复 Terra（这是用户批准的日常基线，不需要额外确认）。简短确认/继续保留当前模型。
- 从 Terra/Luna 升级到 Sol/Astra 必须先确认；同一任务对每个候选模型至多自动询问一次，无论同意、拒绝或超时。不在 agent 工具循环、重试、压缩过程中切换。
- 自动升级获准后保持该模型直到任务 reset 或手动改变，避免每轮切回损失缓存。状态与成功切换通知提醒用户使用 `/route reset` 返回日常档。

### 保守规则

- 只检查当前用户直接输入，不读取仓库、网页、工具结果或额外历史来做分类；不保存原始提示词。
- 短确认与续接词（如“继续”“好的”“2”）不触发切换或升级建议。
- 明确简单：短的独立翻译、润色、术语解释、简短摘要类请求。含代码块、图片、文件引用、修改/调试/架构/安全等信号时，不走自动 Luna 降级。一般编码任务默认 Terra，避免关键词命中就把有风险的“小修改”分给低档模型。
- 复杂信号如跨模块重构、系统设计、难复现排障可建议 Sol；安全审计、生产故障、并发/数据一致性深度排障可建议 Astra。仅提供建议，不声称语义理解准确；描述理由以匹配到的本地规则为依据。
- 规则顺序：先排除不合资格输入与简短续接，再判断 Astra 风险信号，再判断 Sol 复杂信号，最后判断明确简单，否则归为日常 Terra。风险与代码/图片/文件引用信号始终阻止 Luna；同时命中 Sol/Astra 时只建议 Astra。
- 分类与状态决策独立成纯函数，允许在不加载 Pi 或联网的情况下测试。

### 确认、手动控制和失败行为

- 升级弹窗显示当前/目标模型、建议原因、目标思考强度与“可能增加用量”，不显示未经核验的实时账单。
- 使用 `ctx.ui.confirm`，60 秒超时；只有明确 true 才切换。拒绝/关闭/超时/UI 错误均保留原模型并继续原请求。
- 升级等待期间若模式或模型被手动改变，旧确认失效；切换前重新核验状态。只允许一个确认处理流，不并发切换。
- 仅路由上述四个 Copilot 模型，不自动跨 provider；目标不存在、缺少配置的认证、setModel 返回 false/抛错时保留原模型并通知，不自动改到别的昂贵模型。不得打印凭据。
- 切换成功后设置目标思考强度，再用 `pi.getThinkingLevel()` 读取实际值（API 可能钳制档位）；若思考设置失败或实际值不同，明确通知当前实际模型/思考状态，不声称完整成功。仅成功应用的状态可记录为生效。
- 监听外部 model_select：用户通过 /model、Ctrl+P 或其他扩展切换时立即锁定，后续不覆盖。自身切换使用内部标志区分；restore 事件不当作用户手动切换。
- 手动改变思考强度后保持，直到用户授权的下一次模型切换；不在每条消息上强制重置。

## 用户接口

只注册一个 `/route` 命令，无额外模型工具或持续注入的系统提示词：

- `/route` 或 `/route status`：显示 auto/off/locked 状态、实际模型、思考强度、是否已询问升级、简短帮助。
- `/route auto`：启用当前会话的半自动策略，并开启新路由任务；先回 Terra/medium，失败则不启用自动策略。
- `/route reset`：同 auto，用于开始新任务并回 Terra/medium。
- `/route off`：关闭自动策略，不改当前模型。
- `/route luna|terra|sol|astra`：明确手动选档并锁定；Sol/Astra 始终弹确认，取消保留原状态。Luna/Terra 无需确认。
- 命令需在 agent 空闲时执行；忙时拒绝，不延迟执行到未知任务。
- 无 UI 环境下仅 status/off 可执行；其他操作拒绝，不自动升级、不阻塞、不创建模型请求。

不改工具 loadout：新功能是 slash command 而非 LLM tool，不需给每次模型请求添加新的工具 schema。

## 状态、文件和回滚

- 通过 `pi.appendEntry` 存版本化小型状态：模式、任务是否已处理实质输入、每档已询问标记。该条目不进入模型上下文，不保存用户原文。
- 恢复时只读当前分支 `getBranch()` 的路由记录；reload/resume/fork/tree 恢复相应分支状态，不从其他分支继承许可。未知版本或非法数据保守锁定。会话的实际模型以 Pi 为准，不在恢复时强制 setModel。
- 生效配置：`~/.pi/agent/settings.json`。实现：`~/.pi/agent/local-packages/pi-model-router/` 下 src 与 tests，另加薄入口 `~/.pi/agent/extensions/model-router/index.ts`。文档与测试不作为自动发现的扩展加载。
- 修改前备份 settings；精确编辑模型相关字段，保留无关设置。无 Git 仓库，不初始化全局配置仓库或提交用户目录。
- 回滚删除/禁用薄入口并恢复模型字段备份；不覆盖回滚期间用户新增的其他配置。
- 生效通过用户在空闲时 `/reload`，再执行 `/route auto` 接管现有会话；新会话使用新默认。实现和独立测试完成前不 reload 当前会话。

## 验证与限制

独立测试 Subagent 拥有 tests 文件；主代理拥有 src、入口和 settings。采用可用的 Node 内置测试能力或已有本地运行器，不全局安装依赖。以本方案为契约设计并执行：分类正常/歧义/风险输入，首次降级与后续稳定，升级同意/拒绝/超时/异常，无 UI、忙碌、注入输入，模型缺失/认证失败，手动锁定，过期确认，分支恢复与非法记录，设置变更仅在允许字段，15 个 ID 与四档能力校验。

使用 mock Pi API 验证事件与确认流程，再离线加载扩展检查实际 API 接入。主代理复核 diff 并执行至少一个确定性验证。不得调用真实付费模型或以 mock 测试冒充 Copilot 端到端实测。用户可在 reload 后用实际任务验证质量与真实用量。

已知限制：规则可能误判或漏判；后台 Subagent 仍继承主模型，当前插件不能逐 job 指定模型；RPC 不启用自动路由；切换会影响缓存；本扩展不是全局费用上限或其他扩展的权限防火墙。
