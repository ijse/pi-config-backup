# Changelog

## 0.1.0

Initial Git-distributed version (not an npm release).

- Independent status indicator and `/skill-monitor` turn/history/available views.
- Separate successful reads, range-limited/truncated reads, native explicit skill expansion, and discovered/prompt-advertised skills.
- Current-branch replay on reload, resume, session changes, and compaction without duplicate evidence.
- Read-only TUI panel, RPC report fallback, and UI-less protocol safety.
- Regression coverage for in-flight persistence races, oversized-line warnings, and file-level skill symlinks.
- English and Chinese getting-started documentation, behavior/design notes, and development checks.
